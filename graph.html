Semantic topology

A live map of the conceptual space underlying this research. Nodes are key constructs weighted by theoretical centrality; edges encode semantic proximity between ideas. How?

The contour lines show spreading activation — a computational model of how concepts in memory illuminate each other along associative pathways (Collins & Loftus, 1975). The topography is the same mathematics as a gradient descent loss landscape: peaks form where activation concentrates, valleys where it is absent. Tighter contours = steeper gradient = faster change in activation.
